## 1. Pick a folder

rotli asks for one folder. That folder is your vault: every note you write is a plain Markdown file
inside it. Choose an empty folder to start fresh, or one that already has Markdown notes in it.

Rotli Web works the same way: Chrome, Edge, and Arc open the folder directly, and other browsers reach it
through [Rotli Helper](/resources/rotli-helper/).

## 2. Try the Welcome folder

A new vault opens with a **Welcome** folder: nine short lessons on writing, tasks, tables, links,
views, files, and AI. Each one is an ordinary note, so edit them freely and delete the folder when
you're done. **Settings → General → Show me around** runs a short guided tour.

## 3. Learn six keys

| Key | What it does |
| --- | --- |
| **⌥Space** | Bring rotli up from anywhere on your Mac |
| **⌘T** | New note |
| **⌘K** | Search notes, files, chats, and actions |
| **/** on an empty line | Insert a block: heading, task list, table, and more |
| **[[** | Link to another note |
| **⌘0** | Show or hide the sidebar |

Every shortcut can be changed in Settings.

## 4. Keep what matters in Main

**Main** in the sidebar is your own arrangement of the notes you reach for. Right-click a note and
choose **Add to Main**, or drag it in. Main never copies or moves a file; it's a view over the same
folder. Star a note to keep it in Quick access.

## 5. Optional: turn on more

- **The Librarian** files new notes into your folder's structure while you keep working in Main.
- **Chat** can use an on-device model or a tool you already have. See
  [What does AI see in rotli?](/resources/ai-and-your-notes/).

Nothing here is required. A folder and a note is a complete setup.
