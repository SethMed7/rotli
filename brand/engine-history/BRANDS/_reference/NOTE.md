## What the board specifies (transcribed)

**1 · Primary logo** — `rotli` wordmark, lowercase, warm rounded sans, in Cocoa. The leading `r` has a
distinctive curled/looped tail — the signature glyph.

**2 · Secondary logo** — the `r` mark alone (same curled-tail `r`), for compact use (app icon, menu bar,
favicon, avatar).

**3 · Iconography** — outline-style set, each with a one-line description on the board:
Text Notes ("Structured notes for docs and markdown") · Sheets ("Organize data in clean, flexible
tables") · Quick Notes ("Capture thoughts in a flash") · Calendar ("Local and synced calendars in one
view") · Transcript ("Turn speech into clear transcripts") · Action Items ("Track tasks and get things
done") · Tags ("Smart labels for flexible organization") · Reminder ("Calm nudge for gentle prompts") ·
Sync ("Balanced loop for seamless updates") · Search ("Explore with clarity and focus").

**4 · Color palette** — Cocoa `#3A3028` · Clay Blush `#C97E62` · Peach Cream `#F2D6C2` · Linen `#F8F2E9` ·
Olive Moss `#8D9A76`.

**5 · Typography** — primary font direction **Satoshi / General Sans**. Heading: Satoshi Bold 32/40 ·
Subheading: Satoshi Medium 20/28 · Body: Satoshi Regular 14/22 · UI Label: Satoshi Medium 12/16.

**6 · Light mode** + **7 · Dark mode** — UI mockups: warm Linen ground in light, deep warm Cocoa ground in
dark; the `rotli` wordmark + `r` mark top-left; a left icon rail; cards with action items (Olive
checkmarks), a Clay progress bar, quick-note and sync rows, and an "Upcoming" agenda with Clay timestamps.
The icon rail shows: Sheets, Text Notes, Reminder, Calendar, Action Items.
