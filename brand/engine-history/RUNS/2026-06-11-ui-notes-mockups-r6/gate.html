A · Chat — the Inbox chassis, conversation use-case

Same shell grammar: list pane = your chats (model chip, linked-note tag, time), content = the thread, composer at the bottom. Typing /model opens the model menu — bundled model first, anything else you've configured (Ollama auto-discovered), switchable per-chat mid-conversation. Chats are tabs like everything else: split panes = several conversations side by side. Transcripts live in .rotli/chats/ — never in your notes.

B · A chat tagged to a note — done talking, summary already written

Tag any note into a chat (/note or drag). The note rides alongside; the model can read it and — only when you say so — edit it. The freshest edit sits on the peach tint and fades as it settles. Close the chat and there's nothing to clean up: the note is the summary; the transcript is a sidecar you can reopen or forget. Works the other way too: “start a new note from this chat” mints the note with the conclusion as its body.

C · Ask while writing — ⌘J inside Notes

Your “small button / hotkey while taking notes” ask: ⌘J (or the spark at the end of the format bar) opens a tiny ask card at the caret — a question, a word, a rephrase. Insert the answer or discard it; either way the popover is gone and you're still writing. Escalation path: “continue in Chat” lifts the exchange into a full chat tagged to this note.
