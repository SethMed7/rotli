D · Mail providers — Proton first

Confirmed: Proton works, and it fits rotli's soul better than any other provider. Proton doesn't speak IMAP directly (zero-access encryption), so Proton ships Proton Mail Bridge — a small app that runs on your Mac, decrypts locally, and exposes standard IMAP/SMTP on localhost. rotli talks to Bridge like any IMAP server: your mail never transits anyone's cloud unencrypted, and the decryption happens on your machine. That's the local-first story, kept end-to-end. (Bridge requires a paid Proton plan — rotli detects Bridge and walks the user through it.)

Support order

1stProton Mail
Via Proton Mail Bridge (localhost IMAP/SMTP, decryption on-device). First-class onboarding: detect Bridge → guide install → connect. The privacy-aligned flagship path.
2ndGmail / Google Workspace
Gmail REST API — required for the split-brain read state (mark read locally without marking the server). OAuth, token in Keychain.
3rdEverything else
iCloud, Fastmail, Outlook, any IMAP — the universal fallback via the same MailProvider interface.
