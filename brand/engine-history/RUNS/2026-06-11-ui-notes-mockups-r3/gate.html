notes module — UI/UX mockups · round 3 · 2026-06-11 · gate (live render, kit tokens only)

Round 3 answers the maintainer's brief with two research passes behind it (competitor love/hate: Apple Notes, GoodNotes, Evernote, Bear, Craft, Obsidian, Notion, UpNote, iA Writer · premium standards: Linear, Raycast, Things, Superhuman, Material/Radix). Digest first, then the frames.

What wins hearts (adopted)
  • Bear's pane collapse (editor-only / list+editor / all) — the cleanest single-pane story in the category → frame C.
  • Craft's selection toolbar + per-doc typography (small surface, beautifully defaulted) → frame D.
  • iA Writer's focus mode (~65ch measure, typewriter, paragraph dimming) → frame F.
  • Raycast/Linear ⌘K: top-third anchor, never vertically centered (list growth jumps), recents on empty, real shortcuts taught inline → frame G.
  • One state grammar (Material state-layers, Radix radius scale, one focus ring) → frame H, and applied to every mock here.
    • What loses users (designed against)
  • Apple Notes' Aa popover — formatting hidden two taps deep, "two passes for bold+italic" → we use a selection bubble; the Aa panel holds only paragraph/typography, never inline marks.
  • Non-native feel (GoodNotes' Mac port, Notion lag) — instant everything stays law.
  • Lock-in anxiety (Apple Notes export, Evernote pricing) — plain .md + visible marks; underline ships as <u>, highlight as ==…==; font size lives in a styling layer, never written into the document.
  • Forced chrome — every rail optional; the window collapses to just the note.

    C · Formatting while typing — bubble for marks, Aa for typography

    The research split, applied. Inline marks (bold/italic/underline/strike/highlight/code/link) live in a selection bubble — it appears only when text is selected, above the selection, and writes visible markdown (**…**, ==…==, <u>). Typography (paragraph style, text size, measure) lives in the Aa panel — an editor styling layer saved per-note to .rotli/, never written into the document (Apple Notes' mistake inverted; Craft's loved per-doc styling kept).

    The law: hover is always the same ink-overlay (7% light / 8% dark) on the element's own shape — never a new color, never a shape change. Selection is always tint (peach family) or surface-merge; clay is reserved for the single punctuation per pane (selection bar, focused-tab edge, primary button). Focus-visible is always a 2px clay ring, 2px offset, keyboard-only. Radii come from the scale; transitions are 120–180ms ease-out, exit faster than enter, and frequent actions (hover, tab switch) animate opacity/transform only or not at all.
