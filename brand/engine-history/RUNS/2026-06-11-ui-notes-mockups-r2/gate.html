I · Chat on a note — the living summary

Future · concept only — ships with the breve round, shown to lock the structure now

Seth's idea made concrete: the same note, open twice. Left — the plain editor. Right — the note opened as a chat: the note body is the living summary (always primary, always the artifact you keep); the conversation is scaffolding, collapsed into one drawer row. Talking edits the note — the freshest AI edit sits on a peach tint that fades to ground. By the end of any conversation, the summary already exists. A chat is just another tab type — which is why the tab system above carries a type glyph from day one.
