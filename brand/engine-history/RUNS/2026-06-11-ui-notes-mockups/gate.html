    Round-1 calls to make (the gate)

    1. Layout law: three-pane Apple-Notes default; tabs + split view demoted to a later power layer. Approve?
    2. Module switcher: labeled pills in the title bar (as mocked) vs a quieter icon-only rail with hover labels.
    3. Corpus path + shape: ~/rotli, sidebar folders = disk folders, 3-line frontmatter, .rotli/ for the index.
    4. Quick-capture default: lands in Inbox folder; ⌘⏎ saves and opens the full window.
    5. Hotkey canon: ⌥Space everywhere (docs currently drift between ⌥Space and ⌥,).
    6. Storage cards copy: “This Mac · rotli sync (later) · Your cloud (later)” — is this the honest round-1 story?
