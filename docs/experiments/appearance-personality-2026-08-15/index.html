Catalog 04

Recent Bun options

Rotli already runs the latest stable Bun 1.3.14. Only two recent changes map cleanly to current boundaries.

Recent capability Rotli fit Route
1.3.14 · --no-orphansParent death terminates the supervised descendant tree. Direct match for the terminal-owned Tauri dev supervisor. Trial Target `dev:app` only; add lifecycle regression first.
1.3.13 · test --changedUses Git changes and the test import graph. Matches focused iteration without weakening the full check gate. Add New opt-in developer command.
1.3.13 · isolate / parallel / shardFresh globals and multi-worker test execution. Potential CI speedup; shared module state makes immediate adoption risky. Measure Isolation first, parallel second.
1.3.14 · rewritten fs.watchFSEvents-only on macOS; fewer watcher threads. Good Bun hardening, but durable vault watching is a Rust-host concern. Hold Do not move the boundary.
1.3.14 · Bun.ImageBuilt-in decode, transform, and encode pipeline. Could replace a few Sharp checks but not the transformer dependency. Hold Low architectural return.
Experimental network / storeHTTP/2, HTTP/3, global isolated package store. No product need; repository defaults should remain stable. Skip Revisit only with measured need.
